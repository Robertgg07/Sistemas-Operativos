Ejercicio: Mostrar los procesos que más memoria consumen
Hacer un script que muestre los procesos que están utilizando memoria RAM en el sistema.

Formato de salida:
PID --> MEMORIA (%)
1234 --> 12.5%
2456 --> 8.3%
3456 --> 4.7%

Adicionales:
- Opción -u usuario: permite especificar el usuario cuyos procesos queremos mostrar. Si no se especifica, se mostrarán los procesos de todos los usuarios.
- Opción -first n: permite mostrar únicamente los primeros n procesos que más memoria consumen. Si no se especifica, se mostrarán todos.
- Opción -h: muestra una pequeña ayuda explicando cómo utilizar el programa.
